# Process Opportunity Advisor

A lightweight browser application for guided process discovery and structured automation/AI opportunity assessment.

## Run
Open the GitHub Pages URL. No account, API key, model download, installation, backend, or database is required.

## Architecture
Static HTML/CSS/JavaScript hosted on GitHub Pages. Adaptive branching is deterministic and transparent. It identifies signals in employee responses and asks up to two relevant follow-up questions before producing a structured IT handoff.

## Why this release is intentionally lightweight
The discovery problem does not require a general-purpose LLM to demonstrate the workflow. This release minimizes employee friction, cost, external data transmission, and operational dependencies. A later phase could connect the same session/output contract to a City-approved local or hosted LLM where free-form interpretation materially improves the experience.

## Boundaries
This tool performs discovery and triage, not technical feasibility analysis. It does not assert ROI, integration/API availability, security approval, or implementation feasibility.

## Dependencies
- A modern web browser
- GitHub Pages to host the static files
- Internet access to load the page

No third-party JavaScript libraries or model files are loaded.
